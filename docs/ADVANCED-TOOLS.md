# Advanced tools in Prism 1.1.0

1. **RAW:** File → Open accepts DNG, CR2/CR3, NEF, ARW and other LibRaw-supported cameras. Choose exposure, white balance and half-size before Apply. LibRaw performs actual sensor decoding/demosaicing, not thumbnail extraction. Unsupported camera compression returns an error. The result is RGB/8 sRGB; original RAW is unchanged. No ICC-preserving 16-bit document pipeline or saved source RAW re-development is claimed. Limits: 150 MB source, 8000px per side and 32 million developed pixels.
2. **Subject/hair:** Select → Select subject, or the person icon in the Generative AI sidebar. Bundled U²-Net predicts a 320×320 soft saliency mask. Hair mode applies colour-affinity edge refinement at document resolution. Inspect edges, then use Refine selection or mask painting. This is not guaranteed hair reconstruction or a dedicated high-resolution matting network; backlit/translucent hair and busy backgrounds can need manual work.
3. **Brushes:** Brush → Brush settings. Round, Charcoal, Foliage and Calligraphy presets expose spacing, scatter, size/angle jitter, roundness, pressure and tilt. Import a PNG tip (≤1024px, ≤2 MB); dark opaque marks become tip coverage. Settings presets persist locally; imported image tips last for the session. Pointer pressure/tilt logic is implemented; a physical Windows tablet has not been tested. ABR and bristle physics are absent.
4. **Groups:** Layer → Group selected layer accepts `Portrait/Hair/Highlights`. Matching paths share group settings. Folder arrows collapse; the eye changes group visibility without changing members; the percentage opens opacity/blend settings. Groups composite to isolated surfaces before their parent, up to 12 levels. Empty folder nodes and drag/drop group moves are absent. Group metadata participates in undo, save and reopen.
5. **Bézier:** Pen path: click-drag creates smooth handles; drag anchors/handles to reshape; Alt-drag breaks symmetry; Alt-click removes handles; Ctrl-click deletes anchors. Path options sets open/closed state, splits a numbered cubic segment exactly, strokes or makes a selection. Fill path/Enter creates a gradient fill. Paths panel reopens saved anchors/handles. Escape cancels a draft. Project metadata stays editable and follows resizing/affine transformations, while rendered fill/stroke pixels remain raster. No compound Boolean shapes, CSH import or vector-only shape layer engine.
6. **Real inpainting:** select a region, then Filter → Content-aware removal (offline model), or the eraser icon in the AI sidebar. Bundled MI-GAN reconstructs the area from surrounding pixels on CPU, with no running server. Content-aware move uses it by default and keeps moved original pixels on another layer. The network works at 512px over a cropped context; large holes/resampling can show artifacts. Unselected pixels are copied exactly, original layers stay below, and Undo works. Inspect generated details. Text-prompt generation/Expand still uses optional separately installed local Stable Diffusion, not MI-GAN.

The editor rejects inpainting/selection results if the visible document changes while inference runs. A local inference guard prevents overlapping remove/subject operations. CPU performance varies; no GPU or RAM claim is inferred from the user's unknown hardware.

## Offline assets and reproducibility

`public/models/manifest.json` records origins, upstream checksum, conversion details and SHA-256 hashes. `npm run build` verifies all model/decoder/runtime files before building. No automatic model download is performed by the app.

- U²-Net small: https://github.com/xuebinqin/U-2-Net; ONNX distribution https://github.com/danielgatis/rembg/releases/tag/v0.0.0. Upstream rembg MD5 matched `8e83ca70e441ab06c318d82300c84806`.
- MI-GAN: https://github.com/Picsart-AI-Research/MI-GAN; TorchScript distribution https://github.com/Sanster/models/releases/tag/migan. `scripts/export-migan.py` converts the checksum-pinned release using torch 2.5.1+cpu to opset 17. Python/PyTorch are conversion tools only; the Windows app runs ONNX/WASM.
- ONNX Runtime Web 1.30.0 (MIT), single CPU thread. Runtime files are bundled, not fetched from a CDN.
- LibRaw-Wasm 1.6.0 bundles LibRaw 0.22.1, Little CMS and IJG JPEG. Source/build instructions: https://github.com/ybouane/LibRaw-Wasm; source terms/notices are in `licenses/`. The desktop CSP permits Emscripten binding code generation only in the isolated RAW worker; the document keeps `wasm-unsafe-eval` without JavaScript `unsafe-eval`. Renderer HTTP/HTTPS/WebSocket access remains blocked.

Project v3 stores cubic handles and nested groups. v1/v2 still load; older applications reject v3 rather than silently discard new structure.
